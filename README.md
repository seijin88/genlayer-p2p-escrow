# GenLayer P2P Escrow with AI Arbitration

A decentralized escrow solution designed for secure Peer-to-Peer (P2P) crypto-to-fiat trading on GenLayer.

## Key Features
- **Manual & AI Arbitration:** Supports automated AI verification (`gl.nondet`) and manual seller review.
- **On-Chain Proof:** Securely stores proof URLs and balances.
- **Full Lifecycle:** Creation, locking, release, refunds, and cancellation.
- **Robust Logic:** Pre-transfer balance checks to prevent errors.

## Tech Stack
Built on GenLayer with `gl.nondet` for AI integration.
